### 2.2 주요 결정 사항
- **화면 배율**: 논리 해상도 960×600, `pxPerCm = 11` → 구피 성체 44px, 새끼 약 17px, 안시 성체 약 132px. 16은 안시가 너무 크고, 8은 무늬가 안 보이고 새끼를 클릭하기 어려워 11로 정함.
- **헤엄 속도**: 종 데이터의 `swimSpeedCm`(cm/초) × `pxPerCm`. 구피는 5cm/초.
- **변이 구조**: `SpeciesConfig.variants`는 `VariantConfig[]` 객체 배열이다. 기획서 13.2 예시의 문자열 배열은 옛 형식이다. 외형은 데이터 조합(몸색·배색·지느러미색·몸/꼬리 무늬·꼬리 모양·지느러미 크기·알비노·메탈릭·덤보)으로 표현하고, 렌더러가 해석한다.
- **변이 등장 확률**: 노멀 70 / 레어 25 / 유니크 5 (`BALANCE.variantRarityWeights`). 같은 등급 안에서는 균등하게 뽑는다. 1만 회 시뮬레이션으로 확인함.
- **무늬 고정**: 개체마다 `patternSeed`가 있어 프레임마다 같은 무늬가 그려진다.
- **화폐 단위**: '코인'. 표기는 "🪙 100" 형태.
- **재미 요소 추가 (기획서 9.2~9.6)**: 교감·깜짝 발견·수집·배우기·가벼운 목표. MVP에는 이름 짓기와 감정 표현만 넣고, 나머지는 v0.2 / v0.3 / 이후로 나눔 (기획서 12장).
- **판매 표현**: "판매" 대신 "입양 보내기". 팁·상금·보물로 물고기를 떠나보내지 않고도 코인을 벌 수 있게 함.
- **종 외형 분기**: `SpeciesConfig.shape`("guppy" | "corydoras" | "ancistrus")로 렌더러에서 분기한다. 아직 구피 드로잉만 있고 나머지는 구피 모양으로 대체된다.

### 2.3 개발용 기능
- `http://localhost:5173/?variants` — 구피 변이 10종을 한 마리씩 풀고 `[등급] 이름` 이름표를 표시한다.
- 개발 모드에서만 `window.game`으로 게임 객체가 노출된다. 콘솔·Playwright 디버깅용이다.

## 5. 작업 로그

### 2026-11-05
- Vite + TypeScript 프로젝트 초기화, 기획서 13.1 디렉터리 구조 생성. 아직 쓰지 않는 파일은 스텁으로 둠.
- 어항 배경 구현: 물 그라데이션, 모래·자갈(고정 시드), 빛줄기, 수면 출렁임, 유리 반사·테두리. 움직이지 않는 부분은 오프스크린 캔버스에 한 번만 그림.
- 구피 1마리 유영 구현: 중층 범위에서 목표 지점 랜덤 선택, 감속 접근, 가끔 머뭇거림, 방향 전환 시 몸이 뒤집히는 연출, 속도에 비례한 꼬리 흔들림.
- 크기 조정: 구피가 너무 작아 `pxPerCm` 10 → 16, 속도 7 → 5cm/초.
- 구피 변이 10종 추가 (노멀 3 / 레어 4 / 유니크 3). 기획서 6.1에 변이 표 추가.
  - 노멀: 야생형, 레드 테일, 옐로우 테일
  - 레어: 블루 그라스, 하프 블랙 레드, 레오파드, 블루 모자이크
  - 유니크: 알비노 풀레드, 플래티넘 덤보, 골드 더블소드
- `?variants` 확인 모드와 개발용 `window.game` 노출 추가.
- 하프 블랙 검은 영역 확대, 덤보 가슴지느러미 윤곽선 추가 (흰 몸과 구분).
- 크기 재조정: `pxPerCm` 16 → 11 (구피 44px). 안시 추가 시 크기 균형과 무늬 가독성을 함께 고려함.
- 이름 짓기 방식 결정: 직접 입력 + 추천 이름 칩 함께 제공, 자동 기본 이름 부여 (기획서 9.2 "이름 짓기 상세").
- 기획 보강: 재미 요소 추가 (기획서 1.2, 2, 3, 9.2~9.6, 11, 12, 14 갱신). 이름 짓기·감정 표현을 MVP 범위에 추가 (CLAUDE.md 반영).
- 웹 배포(S3 + CloudFront + Route 53, CDK)와 보상형 광고(버튼을 눌렀을 때만, 하루 5회, 비맞춤·아동 대상 처리) 설계 문서 작성.
