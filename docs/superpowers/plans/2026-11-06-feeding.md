# 먹이 주기 + HUD 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 수면을 클릭하면 먹이가 가라앉고, 배고픈 구피가 쫓아가 먹고, 남은 먹이는 바닥에서 서서히 사라지며, 왼쪽 위에 날짜·시간 HUD가 보인다.

**Architecture:** `Food`(개체)는 가라앉기·사라지기만 하고, `FeedingSystem`(시스템)이 포만감 감소·목표 지정·먹기를 판단해 `Fish.chase()`로 지시한다. `Game`이 먹이 목록을 갖고 갱신 순서를 정한다. 입력·좌표 변환은 `main.ts`와 `render/`, HUD는 `ui/`의 HTML 요소다.

**Tech Stack:** TypeScript, Canvas 2D, Vite, vitest (node 환경, DOM 없음)

**Spec:** `docs/superpowers/specs/2026-11-06-feeding-design.md` — 구현 전 반드시 함께 읽는다.

## Global Constraints

- 밸런스 수치는 모두 `src/game/balance.ts`의 `BALANCE.feeding`에 둔다. 코드에 숫자를 직접 쓰지 않는다.
- 판단 로직은 `systems/`, 개체 상태는 `entities/`, 그리기는 `render/`, HTML UI는 `ui/`. 종마다 클래스를 만들지 않는다.
- UI 텍스트는 한국어. 코드 주석도 기존처럼 한국어.
- 단위 테스트는 DOM 없이 돈다. DOM·캔버스가 필요한 코드는 순수 함수를 분리해 그것만 테스트한다.
- 커밋 메시지는 기존 관례(영어 conventional commits) + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 작업 브랜치: `feat/feeding`. `main`에 push하면 자동 배포되므로 직접 push하지 않는다.

## Review Focus

1. 물고기 바로 위/아래에 있는 알갱이 → 입이 닿아 실제로 먹는다 (Task 4 시뮬레이션 테스트).
2. 알갱이 하나를 두 마리가 노리다 한쪽이 먹음 → 다른 쪽은 오류 없이 다른 알갱이를 쫓거나 떠돈다 (Task 4).
3. 쫓던 중 포만감이 90에 닿음 → 즉시 쫓기를 멈추고 떠돈다 (Task 4).
4. 아이가 수면을 연타 → 알갱이 수가 40을 넘지 않는다. 벽 바로 옆 클릭 → 알갱이가 어항 밖에 생기지 않는다 (Task 5).
5. 창 크기 변경·고해상도 화면에서 클릭 → 누른 자리에 먹이가 떨어진다 (Task 7 `toLogical` 테스트).

### Task 4: `FeedingSystem`

**Files:**
- Modify: `src/systems/FeedingSystem.ts` (스텁 교체)
- Test: `src/systems/FeedingSystem.test.ts`

**Interfaces:**
- Consumes: Task 1~3 전부
- Produces: `class FeedingSystem { update(dt: number, fishes: Fish[], foods: Food[], tank: Tank): void }` — `foods`에서 먹힌 알갱이를 **제자리에서 제거**(splice)한다.

먹을 수 있는 알갱이: `fish.species.diet.includes("flake") && food.state === "sinking"`. 바닥 먹이 규칙은 4단계에서 확장.

- [ ] **Step 1: 실패하는 테스트**
  - 먹이 없이 `update(300, ...)` 한 번 → `fullness` 60 → 0 (음수 아님); `fullness = 100`에 `update(150)` → 50
  - 배고픈 물고기(400,300) + 알갱이 (450,300), (700,300) → `update` 후 `chasing === true`, 가까운 쪽을 목표로 함 (`mouth`와 450 쪽 거리로 검증하거나 수 프레임 뒤 x가 450 쪽으로 이동)
  - 입 위치에 알갱이를 두고 `update` → `foods.length` 1 감소, `fullness` +8; `fullness = 97`이면 100에서 멈춤
  - `fullness = 90` → 알갱이가 있어도 `chasing === false`, 알갱이 그대로; 쫓던 중 90이 되면 `chasing === false`
  - `state = "settled"` 알갱이만 있으면 쫓지 않음
  - **시뮬레이션**: 물고기 (400, 300), 알갱이 (400, 200) (바로 위). 매 프레임 `food.update → feeding.update → fish.update` 순서로 dt=1/60, 최대 20초 → 알갱이가 먹힘
  - **두 마리 한 알갱이**: 물고기 2마리가 알갱이 1개를 향해 시뮬레이션 → 예외 없이 한 마리만 +8, 이후 둘 다 `chasing === false`
- [ ] **Step 2:** `npx vitest run src/systems/FeedingSystem.test.ts` → FAIL
- [ ] **Step 3:** 스펙 3.3 순서대로 구현.
