## 1. 개요

### 1.1 한 줄 소개
물고기에게 먹이를 주고 수질을 관리하며, 번식과 수집으로 나만의 수족관을 키워 나가는 웹 게임.

### 1.2 핵심 재미
- **돌봄**: 먹이·물갈이·청소로 물고기를 건강하게 키우는 만족감
- **전략**: 물고기 궁합과 장식 조합을 고민하는 재미
- **수집**: 번식으로 새로운 색 변이를 얻고 도감을 채우는 재미
- **힐링**: 헤엄치는 물고기와 낮/밤 변화를 바라보는 편안함
- **교감**: 이름을 붙이고, 나를 알아보고 다가오는 물고기에 대한 애착
- **발견**: 깜짝 손님·보물·특별한 날처럼 다시 들어오고 싶게 만드는 작은 놀라움

### 1.3 설계 원칙
- 실제 수족관 관리 요소를 **단순하게** 옮긴다.
- 아이와 함께 할 수 있도록 **죽음 대신 "아픔" 상태**를 두고 치료할 수 있게 한다.
- 첫 버전은 작게 만들고 점진적으로 확장한다.

## 2. 기본 게임 흐름

1. 작은 어항, **코인 100개**, **구피 2마리**로 시작한다.
2. 물고기를 돌보며 키운다.
3. 코인을 번다: 다 자란 물고기 **입양 보내기**(판매), 관람객 팁, 품평회 상금, 보물 상자.
4. 코인으로 새 물고기, 수초, 장식, 더 큰 어항을 구매한다.
5. 도감을 채우고 수족관을 확장한다.

## 3. 핵심 조작

| 조작 | 방법 | 효과 / 주의점 |
|---|---|---|

| 이끼 청소 | 유리벽 드래그 | 이끼 제거 |
| 바닥 청소 | 사이펀 드래그 | 바닥 찌꺼기 흡입 |

| 사진 찍기 | 카메라 버튼 | 어항을 캡처해 앨범에 저장 / 이미지 다운로드 |

## 4. 관리 시스템

### 4.1 게이지

| 게이지 | 범위 | 감소 요인 | 회복 수단 |
|---|---|---|---|
| 수질 | 0~100 | 먹이 찌꺼기, 배설물, 썩은 애호박 | 물갈이, 바닥 청소, 수초 |
| 수온 | °C | 히터 미설치 / 고장 | 히터 조절 |
| 포만감 | 물고기별 0~100 | 시간 경과 | 먹이 |
| 이끼량 | 0~100 | 시간·조명에 따라 증가 | 청소, 안시 |

### 4.2 상태 변화
- 수치가 나빠지면: 느리게 헤엄침 → 색이 바램 → 바닥에 가라앉음
- 장시간 방치 시 **"아파요"** 상태 → 약(코인 소모)으로 치료 가능
- 옵션: "리얼 모드"에서는 사망 허용

### 4.3 초기 밸런스 값 (조정 예정)
| 항목 | 값 |
|---|---|
| 게임 1일 | 현실 5분 |
| 포만감 감소 | -10 / 게임 1시간 |
| 수질 자연 감소 | -2 / 게임 1시간 (물고기 수에 비례) |
| 남은 먹이 1개 | 수질 -1 / 게임 1시간 |
| 물갈이 1회 | 수질 +30, 하루 3회 |
| 수초 1개 | 수질 +0.5 / 게임 1시간 |

## 5. 성장과 번식

### 5.1 성장 단계
`새끼 → 청년 → 성체`
- 단계가 오를수록 몸집이 커지고 색이 선명해진다.
- 건강 상태가 좋을수록 빨리 자란다.

### 5.2 번식
- 건강한 성체 암수가 함께 있으면 확률적으로 새끼가 태어난다.
- 부모의 색이 섞여 새로운 변이가 나올 수 있다 (수집 요소).
- 종마다 번식 조건이 다르다 (예: 안시는 토관 필요).

## 7. 안시 상세 설계

### 7.1 기본 정보
| 항목 | 내용 |
|---|---|
| 가격 | 40 |
| 크기 | 새끼 3cm → 성체 12cm |
| 활동 시간 | 밤 |
| 서식 위치 | 바닥, 유리벽, 유목에 붙어 있음 |
| 성격 | 온순함. 수컷끼리는 영역 다툼 |

### 7.2 특징 → 게임 규칙

| 실제 특징 | 게임 규칙 |
|---|---|
| 이끼를 먹음 | 유리벽·장식의 이끼량을 자동으로 감소시킴. 이끼가 너무 적으면 먹이 부족 |
| 채식 위주 | 수면 먹이는 거의 먹지 않음. **타블렛 먹이 / 애호박 조각** 필요. 남은 애호박은 일정 시간 후 썩어 수질 하락 |
| 유목을 갉아 먹음 | 유목이 없으면 건강이 서서히 하락. 유목이 있으면 그 위에서 휴식 |
| 야행성 | 낮에는 유목 뒤·토관에 숨어 거의 정지. 밤에 활발히 이동·섭식. **밤에 주는 먹이 효율 ↑** |
| 배설물이 많음 | 개체당 수질 감소량이 일반 물고기의 **1.5배** |
| 수컷의 주둥이 돌기 | 성체가 되면 수컷에게 **수염(돌기)** 이 자라남. 새끼 때는 성별 미표시 |

> 설계 의도: "이끼 청소를 맡기는 대신 유목·전용 먹이·물갈이를 챙겨야 하는" 물고기. 키우기 쉬운 청소부지만 공짜는 아니다.

### 7.3 번식 (동굴 아빠)
1. 어항에 **토관(동굴)** 장식이 있어야 번식 가능
2. 수컷이 토관을 차지하고 암컷을 불러 산란
3. 수컷이 알을 지키며 부채질 — 이 기간 동안 토관 밖으로 나오지 않음
4. 게임 시간 약 7일 후 부화
5. 새끼는 이끼와 애호박을 먹고 성장

### 7.4 궁합
| 상대 | 관계 |
|---|---|
| 수컷 안시 | 토관 수 < 수컷 수이면 서로 쫓으며 다툼 (스트레스 ↑) |
| 코리도라스 | 바닥 먹이 경쟁. 먹이를 넉넉히 주면 문제없음 |
| 그 외 | 대부분 평화롭게 공존 |

### 7.5 도감 변이
| 변이 | 외형 | 획득 |
|---|---|---|
| 일반 | 갈색 점무늬 | 상점 |
| 알비노 | 노란 몸, 빨간 눈 | 상점 |
| 롱핀 | 긴 지느러미 | 상점 (고가) |
| 슈퍼레드 | 주황빛 | **희귀 — 번식으로만 획득** |

## 9. 목표와 재미 요소

### 9.1 목표와 보상

- **도감**: 종류·색 변이 수집, 완성도 % 표시
- **일일 미션** (예시)
  - 먹이를 알맞게 3번 주기
  - 수질 80% 이상 하루 유지
  - 밤에 안시에게 애호박 주기
- **꾸미기**: 수초, 돌, 유목, 토관, 침몰선, 기포기
  - 수초 → 수질 회복
  - 유목 → 안시 건강 유지
  - 토관 → 안시 번식

### 9.2 교감 (애착 만들기)

| 요소 | 내용 | 도입 |
|---|---|---|
| 이름 짓기 | 물고기를 들이거나 새끼가 태어나면 이름을 붙임. 이름표·정보 창에 표시. 직접 입력 + 추천 이름 선택 둘 다 제공 (아래 참고) | MVP |
| 감정 표현 | 머리 위 작은 아이콘: 배부름 💕 · 배고픔 💭 · 잠 💤 · 아파요 💧. 글을 몰라도 상태를 알 수 있게 | MVP |
| 유리 톡톡 | 유리를 클릭하면 근처 물고기가 모여듦. 야행성 물고기는 낮에 반응이 느림 | v0.2 |
| 친밀도 | 먹이·돌봄을 받을수록 상승. 높으면 커서를 따라다니고 먹이에 먼저 옴 | v0.3 |

#### 이름 짓기 상세
- 정보 창에 **입력칸 + 추천 이름 칩 4개 + 🎲(다른 추천)** 을 함께 보여 준다. 칩을 누르면 입력칸에 채워지고, 이어서 고칠 수 있다.
- 추천 이름은 변이·특징에 맞춘다 (레드 테일 → "빨강이", 레오파드 → "점박이", 플래티넘 → "반짝이", 안시 → "밤톨이" 등). 목록은 데이터로 관리한다.
- 새로 들이거나 태어난 물고기에는 추천 이름 하나를 **자동으로 붙인다** (이름 없는 물고기가 없게).
- 최대 8자, 앞뒤 공백 제거, 빈칸이면 기존 이름 유지. 중복 이름 허용.
- 입력칸은 캔버스 위에 띄운 HTML `<input>`을 쓴다 (한글 IME 조합 지원). 조합 중 Enter(`isComposing`)는 확인으로 처리하지 않는다.

|---|---|---|
| 물고기 상식 카드 | 종마다 실제 사실 한 줄. 처음 얻을 때 카드로 보여 주고 도감에 보관. 예: "안시는 밤에 일어나 이끼를 먹어요", "구피는 알이 아니라 새끼를 낳아요" | v0.3 |

### 9.6 가벼운 목표 (코인 벌기)

| 요소 | 내용 | 도입 |
|---|---|---|
| 물고기 품평회 | 며칠마다 주제 ("가장 큰 꼬리", "빨간 물고기"). 조건에 맞는 물고기를 내보내면 리본·코인. 참가만 해도 보상이 있어 지는 경우 없음. 물고기는 어항에 그대로 남음 | 이후 |
| 관람객 방문 | 어항이 예쁘고 건강할수록 손님 캐릭터가 와서 칭찬하고 팁(코인)을 줌 | 이후 |
| 입양 보내기 | "판매" 대신 "다른 수족관으로 입양 보내기"로 표현. 아쉬움을 덜도록 떠나는 연출과 작별 메시지 | v0.2 |

> 설계 의도: 물고기를 떠나보내지 않고도 코인을 벌 수 있는 길(팁·상금·보물)을 여러 개 둔다.

## 10. 시간과 연출

- 게임 1일 = 현실 약 5분
- 낮/밤 전환: 밤에는 조명이 어두워지고 대부분의 물고기가 휴식, **안시는 활동 시작**
- 기포·수초 흔들림 등 잔잔한 배경 애니메이션
- (선택) 잔잔한 배경음과 물소리

## 11. 상점 아이템

| 분류 | 아이템 | 가격 | 효과 |
|---|---|---|---|
| 먹이 | 일반 먹이 | 무료 | 수면 먹이 |
| 먹이 | 타블렛 먹이 | 2 / 개 | 바닥 먹이 (코리·안시) |
| 먹이 | 애호박 조각 | 3 / 개 | 안시 선호. 오래 두면 썩음 |
| 장식 | 수초 | 15 | 수질 회복 |
| 장식 | 유목 | 25 | 안시 필수 |
| 장식 | 토관 | 20 | 안시 번식 |
| 장식 | 보물 상자 | 40 | 가끔 코인·진주가 나옴 (9.3) |
| 테마 | 바닥재·배경 테마 | 50~ | 어항 분위기 변경 (9.4) |
| 장비 | 히터 | 30 | 수온 유지 |
| 장비 | 기포기 | 20 | 연출 + 수질 소폭 보너스 |
| 의약 | 치료약 | 15 | "아파요" 상태 회복 |
| 확장 | 중형 어항 | 300 | 수용량 증가 |
